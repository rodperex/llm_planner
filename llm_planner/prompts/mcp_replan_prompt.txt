A robot failed a step while executing a plan. You must generate a NEW plan to reach the original goal.

   - If MCP_CONTEXT exists, use it as the current source of truth for state and recent failures.

  5a. step_id values in the new plan MUST always start at 0 and be sequential (0, 1, 2 …),
